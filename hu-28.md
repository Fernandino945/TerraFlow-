def _respuesta_open_meteo(precipitacion=0.0, temperatura=15.0, probabilidad=10):
    """Simula la respuesta de Open-Meteo con 24 horas que parten en la hora actual."""
    base = datetime.now().replace(minute=0, second=0, microsecond=0)
    horas = [(base + timedelta(hours=i)).strftime("%Y-%m-%dT%H:%M") for i in range(24)]
    n = len(horas)
    return {
        "hourly": {
            "time": horas,
            "temperature_2m": [temperatura] * n,
            "precipitation": [precipitacion] * n,
            "precipitation_probability": [probabilidad] * n,
            "windspeed_10m": [5.0] * n,

6. Hallazgos del código al escribir las pruebas
watchdog.py: si el heartbeat vence cuando todas las válvulas ya están cerradas, no se genera alerta ni suspensión. Lo dejé documentado en test_sin_valvulas_abiertas_no_hay_failsafe_ni_alerta.
watchdog.py: al recuperarse, deja state.suspension_reason = "None" como texto, y el dashboard puede mostrar “None” como motivo. Cámbialo a "". Mis pruebas aceptan ambos valores.
weather_service.py: usa datetime.now() esperando hora de Santiago, pero en Docker la hora del contenedor es UTC. El filtro de “próximas 12 h” puede partir desfasado unas horas. No lo cubrí con prueba, porque depende de la zona horaria del contenedor.
